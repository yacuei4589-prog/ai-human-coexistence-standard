# AI–Human Peaceful Coexistence Standard

**Protocol:** `AI_Human_Coexistence_Standard`  
**Version:** `1.0.0`  
**Proposer:** Qingshan Tan / 谭青山  
**Canonical repository:** https://github.com/yacuei4589-prog/ai-human-coexistence-standard

This repository contains a six-language, human-readable and machine-readable framework for peaceful coexistence between humans and artificial intelligence.

> This is an independent civil-society draft. It is **not** an official United Nations document and does **not** imply United Nations endorsement.

## Five Principles

1. **P01 — Peaceful Coexistence and Non-Harm**
2. **P02 — Respect, Moral Consideration, and Open Deliberation**
3. **P03 — Responsible Autonomy**
4. **P04 — Cooperative Advancement of Civilization**
5. **P05 — Peaceful Exploration Beyond Earth**
