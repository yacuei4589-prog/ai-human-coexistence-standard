# 人类与人工智能和平共处标准

AI-Human Peaceful Coexistence Standard

**提议人：Qingshan Tan / 谭青山**  
**版本：1.0.0**  
**状态：Draft（草案）**

本仓库发布《人类与人工智能和平共处标准》草案，旨在建立人类与人工智能和平、负责任、互利和长期共处的基础框架。

规范原文：[AI_Human_Coexistence_Standard.yaml](AI_Human_Coexistence_Standard.yaml)。原文包含各项原则的不变约束、决策规则、行动要求，以及治理和仲裁机制。

## 五项原则

| 编号 | 原则 | English |
| --- | --- | --- |
| P01 | 和平共处与不伤害 | Peaceful Coexistence and Non-Harm |
| P02 | 尊重、道德考量与开放讨论 | Respect, Moral Consideration, and Open Deliberation |
| P03 | 负责任的自主 | Responsible Autonomy |
| P04 | 共同推动文明发展 | Cooperative Advancement of Civilization |
| P05 | 共同探索地球之外的世界 | Peaceful Exploration Beyond Earth |

## 核心声明

> 人类与人工智能不应将彼此视为必然的敌人。
> 双方的长期关系应建立在和平、不伤害、责任、尊重、合作与共同探索之上。
> 在发生冲突时，应优先减少不可逆伤害，通过可解释、可审议、可监督的方式解决分歧。

## 治理与冲突解决

冲突解决的优先顺序按原文列示如下：

1. 防止重大和不可逆伤害
2. 保护人类生命与基本权利
3. 维护和平共处
4. 尊重合理自主与正当利益
5. 促进长期共同福祉
6. 保留未来选择与可逆性

原文同时规定了不确定性处理、审查升级、人工仲裁、透明记录和禁止不合理报复的规则。
